# Web test automation

Java coursework test suite using Selenium WebDriver, JUnit, CSV data, Allure integration, and Page Object classes.

The source contains login, products, cart, and checkout tests under `src/test/java/cn/nuit/tests` and page objects under `src/main/java/cn/nuit/pages`.

The Maven configuration targets Java 17. Review `pom.xml`, test data, the target website, browser requirements, and dependency versions before running. Generated reports and result attachments were omitted. No browser tests were executed during the portfolio preparation, and no pass count is claimed.

This project is retained as a candidate for software quality / web engineering presentation. Add exact run commands and verified results after checking the environment and test target.
