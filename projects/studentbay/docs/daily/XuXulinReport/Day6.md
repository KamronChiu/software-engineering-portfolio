**📝 详细工作内容**

承接 Day 5 末尾"明日计划"预告的**阶段 4 · 既有扩展与总结**（T4.1 → T4.9），全部按设计文档落地。这一阶段的主线是：把前面几轮"能用"的能力再往前推一层——分类不再是写死的、搜索能分页能查教材编号、发布页按分类出参数、足迹/擦亮/置顶/推荐这些真实二手平台都有的功能补进来，同时保证不推翻已完成的内容，只做增量。

### 1. 分类表 + 首页分类 Tab（T4.1）

- 新增 `Category` 实体（表 `categories`：`name` 唯一、`parent_id` 预留二级分类、`icon`、`sort`、`status`、时间戳）+ `CategoryRepository` + `CategoryController`。`GET /api/categories` 只返回 ENABLED，且带 `children` 形成分类树。
- `DemoDataInitializer.seedCategories()` 预置 6 个一级分类（教材资料/数码产品/骑行装备/宿舍生活/服饰美妆/其他），带 emoji 图标，`count()>0` 就跳过，重复启动不重复插入。
- 前端 `index.html`：`category-rail` 改成空容器，新增 `loadCategories()` 拉接口渲染分类 Tab（图标+文字）和筛选下拉；发布页分类下拉同样改为接口读取。以后新增分类只动数据库，不用改页面。

### 2. 搜索增强（T4.2）

- **分页**：`ProductController.list()` 新增 `page/size`，返回 `{items,total,page,size}`。前端 `initHome` 改成每页 20 条，页面下方"加载更多"按钮按 `(page+1)*size < total` 显隐，点一次翻一页追加卡片。
- **关键词匹配扩大**：标题/描述之外，新增 `isbn`、`courseCode`、`moduleName` 三个字段参与匹配（空值自动跳过），输入 ISBN 或课程编号就能找到对应教材。
- **热搜词**：新增 `HotKeyword` 实体（表 `hot_keyword`，keyword 唯一 + count 计数）+ 仓储 + `GET /api/products/hot-keywords`。搜索时 `recordHotKeyword(keyword)` 计数，接口返回 TOP10。种子数据预置 7 条自然热搜词（教材/机械键盘/自行车/耳机/考研/宿舍/台灯），全新库也有榜。
- **前端**：搜索面板加"最低价 - 最高价"两个数字输入（回车即搜，服务端 `minPrice/maxPrice` 一直支持，之前只是没暴露）；排序下拉加"擦亮优先"；热搜词渲染成一排 chip，点击直接带词搜索。

### 3. 商品参数 / 分类动态表单（T4.3）

- `Product` 新增字段：`brand / size / model / material / color / gender / sportType / isbn / courseCode / moduleName`。`PublishRequest` 同步扩字段，`applyStage4Fields()` 空串一律存 null（避免库里一堆空字符串），`view()` 全部输出给前端。
- 发布页定义 `PARAM_SCHEMAS`：教材→ISBN/课程编号/课程/教材名；数码→品牌/型号；服饰→品牌/尺码/颜色/适用性别；骑行→品牌/尺寸/运动类型；宿舍→材质/规格；其他→无。切分类触发 `renderParamFields()` 重渲染；已填的值暂存在 `paramValues` 缓存里，切换分类不丢；提交时 `collectParams()` 只带非空项。编辑模式（`publish.html?edit=`）回填参数后重渲染。
- 详情页新增"商品参数"区：`renderDetailParams()` 有参数才显示，按"标签:值"渲染成卡片格。

### 4. 最近浏览 / 足迹（T4.4）

- 新增 `ProductBrowse` 实体（表 `product_browse`，`(user_id, product_id)` 唯一约束实现去重）+ 仓储 + 接口：`GET /api/products/browse/recent`（本人倒序）、`DELETE /api/products/browse/clear`。
- `detail()` 里登录且非本人浏览时 `recordBrowse()`：已有记录只刷新时间，没有则新增一行；本人看自己的商品不记足迹（避免卖家自己刷浏览）。
- 新页面 `browse.html` + `initBrowse`（卡片复用 `productCard`，空态提示去逛逛，清空记录二次确认），个人中心"我的服务"宫格加"最近浏览"入口，图标 `⌂`，副标题与其它入口风格一致。

### 5. 擦亮与置顶（T4.5）

- `POST /api/products/{id}/sharpen`：仅卖家本人（否则 403）；同一天只能擦亮一次（按 `sharpenedAt` 的日期判断，重复返回 409），成功置 `sharpenedAt=now`。
- `POST /api/products/{id}/top`：body 带 `hours`（1-720，默认 24），置 `topExpireAt = now + hours`。
- 列表排序：置顶期内（`topExpireAt > now`）永远最前，之后按擦亮时间/发布时间倒序；新增 `sort=sharpen`"擦亮优先"档，置顶到期后自然失效回落到正常排序。
- 前端"我发布的 · 在卖"卡片操作区加"擦亮""置顶"两个按钮：擦亮一键完成；置顶用 `prompt` 输时长（默认 24 小时）。

### 6. 相似商品推荐（T4.6）

- `GET /api/products/recommend?productId=`：取同分类、排除自身与已下架/已售/草稿，复用现成的 `titleSimilarity / normalizeTitle / bigrams` 比价算法算标题相似度，按"相似度 → 发布时间"倒序取前 8。
- 详情页底部新增"为你推荐"区，进详情自动加载，卡片与空态都复用平台组件。

### 7. 成色详情与议价标记（T4.7）

- `Product` 新增 `conditionDetail`（成色/瑕疵说明 ≤500）与 `bargainEnabled`（可议价开关）。**议价 ≠ 砍一刀**：议价只是"可以商量价格"的标识，砍一刀是随机降价功能，两者完全独立。
- 发布页"交易设置"区：可议价开关 + 成色/瑕疵说明 textarea（选填）；详情页 meta 行显示"可议价"角标，描述上方显示成色/瑕疵说明。
- `DemoDataInitializer` 给机械键盘/自行车/耳机等演示商品补议价标记与说明，开箱即有展示效果。

### 8. 图片治理（T4.8）

- 新增 `deleteLocalImages(urls)`：只处理 `/uploads/` 前缀的本地 URL，用 `Files.deleteIfExists` 删除（文件名取 `getFileName()` 拼路径，防路径穿越），外链图片不动。
- `delete()`（删草稿）先删本地图片再删库行，同时清掉该商品的浏览足迹；`update()`（编辑换图）对比保存前后的图片列表，只删被移除的那几张。

### 9. 演示数据 + 验证（T4.9）

- `DemoDataInitializer.enrichDemoProducts()`：给已有演示商品补 ISBN/课程号/品牌/尺码/成色说明/议价标记（字段为空才写，绝不覆盖用户改动）；捷安特自行车预置擦亮、机械键盘预置置顶 48 小时，全新库启动即可演示"擦亮优先/置顶"。
- 接口脚本实测：分页 `page=1` 返回 10 条不重不漏；ISBN `978-7-04-039663-8` 命中《高等数学同济第七版》；课程号 `CS2010` 命中《数据结构课程笔记套装》；浏览足迹去重（重复浏览同一商品仍是 1 行）；擦亮成功、同日重复擦亮返回 409；置顶成功；用带新字段的请求体发一条草稿再删除，顺带验证图片治理路径不报错。
- 浏览器实测：首页分类 Tab / 热搜 chip / 价格区间 / 加载更多（20→30 条）；发布页切"数码产品"参数区正确变成品牌+型号；详情页参数区（品牌·索尼/颜色·黑色）+ 可议价角标 + 成色说明 + 为你推荐 8 张卡片；"我发布的"出现擦亮/置顶按钮；最近浏览页能看到刚看过的商品、清空后空态。

**🐞 遇到的问题以及解决方案**

> 客观记录踩过的坑，便于组内介入与后续复盘。

- **问题1**：后端编译报 `DemoDataInitializer.java:[237,94] 需要')'`，指向议价标记那行。
- **答案**：我想用一行三目把"字段为 null 就设 true 并标记 changed"写完，写了 `(product.setBargainEnabled(true), true)`——但 **Java 没有通用逗号运算符**（逗号只在 for 循环和数组初始化里合法），括号里逗号直接语法错误。拆成 `if (x == null) { 设置; changed = true; }` 三行解决。
- **问题2**：重启后首页热搜榜混进 `SE2101`、`978-7-04-039663-8` 这类测试关键词。
- **答案**：接口联调时我用脚本搜索过这些词，被 `recordHotKeyword` 真实计数了。真机上热搜应该只出现自然搜索词，于是用 mysql 把测试词从 `hot_keyword` 表删掉，只留 6 条种子词。
- **问题3**：PowerShell 里敲 `mysql` 报"无法识别"。
- **答案**：`mysql.exe` 没在 PATH 里，实际在 `C:\Program Files\MySQL\MySQL Server 26.7\bin\` 下，用全路径调用；密码从环境变量 `DB_PASSWORD` 读取，不写死在脚本里。
- **问题4**：浏览器验证时点"加载更多"第一次没反应。
- **答案**：页面刚加载完就立刻点，初始请求的 `busy` 标志还没释放，`load(false)` 被守卫拦下。等 1 秒再点即正常（20→30 条）。属于验证时序问题，代码里的 `busy` 防重入守卫本身是正确的。
- **问题5**：详情页 URL 写成 `?id=18?v=stage4` 时"为你推荐"区报 `Failed to convert value ... 'productId'`。
- **答案**：是我测试 URL 的查询串写错了——第二个参数应该用 `&` 连接而不是 `?`，导致 `productId` 参数值变成 `18?v=stage4` 转 Long 失败。代码本身没问题，改成 `?id=18&v=stage4` 后推荐正常出卡片。
