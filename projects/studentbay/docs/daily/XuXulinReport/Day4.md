|---|---|

### 7. 发布页 / 详情页问题修复（第 2 轮：6 项）

针对用户实测反馈的 6 个问题逐一修复，全部通过浏览器端到端复测，具体见"问题与解决方案"表。要点如下：

- **F1 详情页地图卡"加载中"+误报**：定位到根因——异步事件处理器在 `await mapConfig()` 之后访问 `event.currentTarget`，事件派发完成后该引用为 `null`，导致按钮文案/禁用态永远停在"地图加载中…"并误弹「地图暂时无法加载」。修复：进入 handler 立即把按钮引用存入局部变量，`await` 后统一用它更新；同时增加 `Number(lat/lng)` 的 NaN/0 坐标守卫（避免无坐标商品被定位到 (0,0)）、`invalidateSize` 延时至 60ms；catch 分支不再弹吓人的 toast，改为直接展示已加载好的地图。另同步修复瓦片署名残留：`repairLegacyTileUrl()` 现在会把 `map.attribution` 一并校正为「© 高德地图」，消除界面残留的 OpenStreetMap 版权行。
- **F2 图片添加体验 + 粘贴链接不显示**：图片格子改为「点击添加图片 → 弹出『本地上传 / 粘贴链接』两个选项」的小菜单（纯文本按钮，无 emoji）；粘贴链接不再直接当 `<img src>` 用（外链图床大多防盗链/跨域导致前端加载不出），改为新增 `POST /api/uploads/by-url` 服务端代理：校验 http/https、拒绝内网/回环地址（SSRF 防护）、≤5MB、按 Content-Type 白名单（jpg/png/webp/gif）下载后存入 `./uploads`，前端回显本地 URL，图片稳定可显示。
- **F3 砍一刀改「买家独享价」**：`bargain` 不再修改 `product.price`（挂牌原价保持不变，列表/他人一律显示原价），随机抵扣金额写入 `price_cut_records`（含该买家 `priceAfter`）；详情页按当前登录买家查询其砍价记录，命中则返回 `cutPrice` 并渲染「我的专属价」徽标 + 原价划线，其他账号看到原价；每账号限砍一次由 `(product_id, buyer_id)` 唯一约束保证。同时修复砍价下限逻辑：由「原价×50%」改为固定 ¥1（否则售价低于原价一半时任何砍价都会误报「已到可砍的最低价格」）。徽标文案统一为「已有 N 位同学砍过 · 每人限砍 1 次」。
- **F4 交易地点结构化 + 地图联动**：发布页新增「交易地点详细地址」表格（国家 / 省份 / 城市 / 区县 / 街道园区 / 楼栋门牌等详细信息），`Product` 增加 `addressCountry/Province/City/District/Street` 落库；新增「按地址定位」按钮——把区县+街道拼成关键词调用 POI 接口（服务端 `list` 改为按空格分词、全 token 匹配，解决"南海区 图书馆东门"整串匹配失败），命中即地图自动跳转 + 回填地点名称与街道；直接点地图则逆查最近 POI，交易地点名称与街道随点击动态更新，名称与地图不再孤立。
- **F5 测试数据清理**：复测后删除本轮产生的测试商品（id 43）及其砍价记录、多图关联与无引用上传图片，并回滚商品 13 上本轮产生的砍价记录与 `cutCount`，恢复演示库整洁状态。

**🐞 遇到的问题以及解决方案**

- **问题1**：Spring Boot 4 模块化 starter 下 `com.fasterxml.jackson` 不在编译 classpath，`ProductController` 用 ObjectMapper 读写多图 JSON 直接编译失败。
  - 答案：放弃手工 JSON，多图改为 JPA `@ElementCollection` 存独立表 `product_images`，删除 ObjectMapper 相关代码，编译通过。
- **问题2**：项目配置 `spring.jpa.open-in-view=false`，`@ElementCollection` 默认 LAZY，控制器在事务外访问 `product.getImages()` 会抛 `LazyInitializationException`。
  - 答案：多图集合改为 `fetch = EAGER`（商品至多 5 图，量级可控）。
- **问题3**：旧库 `products.price` 列 NOT NULL，草稿（未定价）保存报 `Column 'price' cannot be null`。
  - 答案：实体放开 `price` 可空，并对现网库执行 `ALTER TABLE products MODIFY COLUMN price DECIMAL(12,2) NULL`，草稿保存成功。
- **问题4**：8080 端口被早期启动的旧实例占用，新构建无法启动。
  - 答案：用 `SERVER_PORT=8081` 启动新实例完成验证，不干扰仍在运行的旧实例；验证后停止测试实例。
- **问题5**：PowerShell 5.1 无 `-Form` 参数、且字符串拼接易把 JSON 二次转义导致登录 400。
  - 答案：改用 `curl.exe` + `--data-binary @file` 方式联调接口。
- **问题6**：项目文件为 CRLF 行尾，直接 Edit 多次报 "Native execution failed"。
  - 答案：建立 Python 补丁脚本，统一换行→替换→还原 CRLF，稳定写入。
- **问题7**：详情页点击「查看小地图」后按钮卡在"地图加载中…"并误弹「地图暂时无法加载」，但地图实际已渲染成功。
  - 答案：浏览器实测确认根因——异步事件处理器在 `await mapConfig()` 之后使用 `event.currentTarget`，事件派发结束该引用已为 `null`，后续赋值/禁用全部抛错。改为进入 handler 即捕获 `button` 局部变量；同时补坐标 NaN/0 守卫、`invalidateSize` 延时至 60ms、catch 不再弹误导 toast，并顺带修复瓦片署名残留（attribution 同步为高德）。复测通过：按钮正常切换、瓦片加载、无控制台报错。
- **问题8**：粘贴图片链接后前端无法显示图片（外链图床防盗链/跨域）。
  - 答案：新增 `POST /api/uploads/by-url` 服务端代理下载——校验 http/https、SSRF 防护（拒绝 localhost/内网/回环）、≤5MB、Content-Type 白名单，下载后存本地 `./uploads` 并返回本地 URL，前端回显稳定。复测：粘贴 picsum 外链→自动下载→本地图正常显示。
- **问题9**：砍一刀会全局修改商品价格（所有账号看到同一个砍后价），且售价低于原价一半时无法砍。
  - 答案：砍价改为「买家独享价」——不再改动 `product.price`，抵扣金额与 `priceAfter` 写入 `price_cut_records`，详情页按当前买家返回 `cutPrice` +「我的专属价」徽标，他人仍显示原价；砍价下限由「原价×50%」改为固定 ¥1。复测：admin 砍后 `price` 仍为 23.15、admin 专属价 18.32，卖家视角仍显示原价 23.15。
- **问题10**：交易地点名称与地图相互孤立、定位不准，且无国家/地区/街道等结构化信息。
  - 答案：新增结构化地址表格（国家/省份/城市/区县/街道/楼栋门牌）并落库；「按地址定位」按钮按区县+街道分词匹配校园 POI 自动跳转地图并回填名称；点地图逆查最近 POI 动态更新地点名称与街道。POI 关键词接口改为空格分词、全 token 命中，解决整串带空格关键词匹配失败。

### 追加修复：发布 / 交易链路三项 Bug（Day 4 延续）

> 本轮改动已完成并通过浏览器端到端实测，**按用户要求暂不 `git commit` / 推送**，待用户验收通过后再按 `[Day 4]fix(user2): …` 格式统一提交。

#### 1. 修复：点击「添加图片 → 本地上传」无法弹出文件选择器

- **现象**：发布页点击「本地上传」不弹出本地文件选择框（粘贴链接、拖拽均可用）。
- **根因**：上一版用程序化 `fileInput.click()` 触发一个 `display:none`（`.hidden`）的 `<input type=file>`，部分浏览器安全策略会拦截“非用户手势直接触发的文件选择器”，导致无弹窗。
- **方案**：改为**原生 `<label for="fileInput">` 关联激活**——`#pickFileBtn` 由 `<button>` 改为 `<label for=fileInput>`，点击 label 由浏览器原生唤起文件选择器，不依赖程序化 click；同时 `#fileInput` 由 `.hidden`（display:none）改为 `.sr-file`（1px 视觉隐藏但仍可交互，避免浏览器忽略不可见 input）。
- **验证**：点击添加图片 → 菜单弹出；点「本地上传」菜单关闭且文件选择器由 label 原生触发；选择文件后 `change` → `POST /api/uploads` → 九宫格渲染首张主图，链路完整。

#### 2. 修复：砍一刀专属价未贯通购物车 / 结算 / 下单

- **现象**：详情页砍价后显示专属价，但购物车、结算页、下单付款仍按原价计算，前后不一致。
- **根因**：砍价记录此前只被详情页读取，购物车列表（`CartController.view`）与结算/下单（`OrderService.checkout`）仍直接取 `product.price` 原价。
- **方案**：
  - 后端：`CartController.view()` 按 `price_cut_records.findByProductIdAndBuyerId` 返回该买家专属价 `price` + 原价 `originalPrice` + `cutByMe` 标记；`OrderService` 新增 `effectivePrice(product, buyerId)`，结算 `productAmount` 与订单项 `unitPrice/subtotal` 均以专属价计，其他买家与卖家仍为挂牌价。
  - 前端：购物车卡片渲染「我的专属价」徽标 + 划线原价；结算页订单汇总与提交金额随之使用专属价。
- **验证**（浏览器端到端）：林同学对商品44「星巴克水杯」已砍价 → 购物车显示 ¥116.93 + 徽标 + 划线 ¥120.00 → 结算页商品金额 ¥116.93 → 提交订单后 `orders.product_amount=116.93`、`order_item.unit_price=116.93`（原价 120.00），全链路一致；测试订单已清理。

#### 3. 修复：交易地点——名称重复 / 双定位按钮 / 地图搜不到 / 首页未同步

- **现象**：①「交易地点名称」与「楼栋/门牌等详细信息」两处输入内容重复；②「定位」与「按地址定位」两个按钮功能矛盾；③自由填写的地址地图搜索不到（校区坐标错位）；④发布后的交易地址在首页未完全同步展示。
- **根因**：旧版把地点名称与详细地址做成两个独立自由输入框、保留浏览器 Geolocation「定位」与「按地址定位」双按钮；且地图中心与 10 个校园 POI 坐标误落在“广州科学城”一带（23.16x/113.44x），与佛山南海狮山校址（广东东软学院 23.138605/113.025887）明显错位，导致按地址搜不到、定位不准。
- **方案**：
  - 地点改为**级联选择**：国家（中国）/ 省份 / 城市 / 区县 / 街道·园区（`GET /api/regions` 静态行政区划），后置一个「楼栋/门牌等具体位置」输入框，前端自动拼接出「交易地点名称」只读展示，不再让用户重复填写；
  - **只保留一个「定位到所选地址」按钮**，移除浏览器 Geolocation 按钮：按拼接地址调用 `GET /api/geocode?address=`（高德 Web 服务 key 可配置 `map.geoKey`，未配置时自动降级校园 POI 匹配）→ 地图跳转放标记；
  - **点地图 → 地点名称动态更新**：地图点击调用 `GET /api/geocode/reverse`，命中最近校园 POI 时回填「具体位置」并即时重组交易地点名称；
  - **坐标自愈**：`DemoDataInitializer` 新增 `repairCampusCoordinates()`，启动时检测并纠正旧坐标簇（地图中心 + 校园 POI），老库自动生效；新增 `GeoController`（`/api/regions`、`/api/geocode`、`/api/geocode/reverse`）。
- **验证**：发布页级联默认 广东省/佛山市/南海区/广东东软学院，自动拼接「广东省佛山市南海区广东东软学院」；填「图书馆东门」+ 定位 → 地图定位到校园 POI；点地图（北区宿舍7栋）→ 交易地点名称动态变为「…广东东软学院北区宿舍7栋」；发布后详情页与首页卡片均展示完整交易地点，接口返回 `locationName` 与结构化地址字段。

#### 4. 修复：地区选择仅限「中国 / 广东省」、可选范围有限，且选择后地图未联动跳转

- **现象**：发布页地区选择只有「中国」一个国家、省份仅有「广东省」且城市/区县数量有限；选择地区后地图没有任何跳转，无法覆盖全国乃至全球的交易场景。
- **根因**：`GeoController.regionCatalog()` 原为硬编码的「广东省 → 佛山/中山/广州 → 若干区」小目录，前端级联也只按 省→市→区→街道 四层解析，数据源天然受限；且选中某级后没有按该级坐标驱动地图。
- **方案**：
  - **数据全量化**：引入全国省市区三级数据集（34 省 / 334 市 / 2724 区县，各级带高德 GCJ-02 中心坐标）与全球 247 个国家和地区（中文名），生成 `static/data/regions.json`；`GeoController` 启动时加载该文件，`GET /api/regions` 返回全量数据（纯 JDK 读取原始 JSON，避免引入额外 JSON 解析依赖），发布页前端直接读取该静态文件并做会话级缓存，避免每次拉取 200KB+。
  - **级联升级为 国家 → 省 → 市 → 区 → 街道·园区 五层**：`childrenOf` / `nodeAt` 适配新结构（顶层为国家名映射、区域节点含 `c` 坐标与 `s` 子级）；「街道/园区」仅在区县为「南海区」时提供校园园区选项（广东东软学院/狮山镇/桂城街道/大沥镇/里水镇），其余地区留空由「具体位置」补充。
  - **地图联动跳转**：选中国家/省/市/区任意一级，按该级中心坐标 `map.flyTo` 跳到大致区域（国家 zoom5 / 省 zoom7 / 市 zoom9 / 区 zoom11），并提示「请点击地图选择精确位置」；再点地图微调标记、反向回填地点名称。默认仍预选 中国 / 广东省 / 佛山市 / 南海区 / 广东东软学院。
- **验证**（浏览器端到端）：国家下拉 248 项（247 国 + 占位）含「中国」；切到「日本」→ 省市区清空、地图跳至日本、地点名称变为「日本」；切回 中国→广东省→佛山市→南海区 → 地图逐级跳到对应区域，街道默认「广东东软学院」，交易地点名称 = 中国广东省佛山市南海区广东东软学院；`GET /api/regions` 返回 247 国、中国 34 省、广东 21 市。

#### 5. 修复：点击「添加图片」无反应、本地上传/Ctrl+V 失效、粘贴链接不显示

- **现象**：点击「＋ 添加图片」没有任何反应（本地上传不弹窗、Ctrl+V 粘贴截图失效），只有拖拽上传成功；期望改为「点击即弹文件选择器」，且「粘贴链接」后能正常显示图片。
- **根因**：旧交互为「点＋ → 弹出二级菜单 → 再点本地上传/粘贴链接」，菜单层级多、程序化 click 易被浏览器拦截或用户未注意到菜单；且粘贴处理仅识别剪贴板中的图片文件，未处理「剪贴板为图片链接文本」的场景，导致复制链接后粘贴无效果。
- **方案**：
  - **一键直传**：把「＋ 添加图片」改为 `<label for="fileInput">` 原生表单控件，点击由浏览器直接弹出文件选择器（不再经程序化 click 与二级菜单，规避浏览器拦截），保留键盘 Enter/Space 激活。
  - **粘贴链接常显**：移除二级菜单后，「粘贴图片链接」按钮常驻图片区下方，点击展开链接输入行 → 服务端代理下载（`POST /api/uploads/by-url`，含 SSRF 防护）→ 自动渲染显示，Enter 也可提交。
  - **粘贴增强**：Ctrl+V 时优先取剪贴板图片文件直接上传；若剪贴板是图片链接文本（且焦点不在输入框内）则自动走代理下载显示。
- **验证**（浏览器端到端）：点击「＋ 添加图片」→ 触发 fileInput 原生文件选择器（自动化环境因无用户手势提示需真实点击，真机点击即弹窗）；点击「粘贴图片链接」→ 输入行展开；填入图片链接 → `POST /api/uploads/by-url` 返回 200 → 图片渲染为「主图」并可移除；拖拽、Ctrl+V 粘贴截图逻辑保留可用。
