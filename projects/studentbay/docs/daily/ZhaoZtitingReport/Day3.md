## 今日完成内容

### 1. 收货地址管理

- 修复地址已经写入数据库，但页面仍提示新增失败的问题。
- 将保存地址与重新加载地址列表拆开处理，避免刷新失败造成错误反馈。
- 新增地址修改接口和编辑表单。
- 接入地址删除接口，并增加删除确认。
- 第一个地址自动设为默认地址。
- 修改默认地址时自动取消其他默认地址。
- 删除默认地址后自动选择剩余地址作为新默认地址。
- 后端校验地址归属，避免用户修改或删除其他用户的地址。

### 2. 订单详情与更多服务

- 新增独立订单详情页 `order-detail.html`。
- 待付款、待发货、已预约取件、待收货和已完成订单均可查看详情。
- 订单详情展示商品快照、交易进度、收货信息、配送方式、支付方式和金额明细。
- 买家可在详情页继续付款、确认收货或查看物流。
- 订单列表新增“更多”按钮，并使用底部服务弹层展示可用操作。
- 更多服务根据订单状态和买卖双方身份展示订单详情、钱款、物流、商品快照和联系对方等入口。

### 3. 商品公开留言

- 新建商品留言数据表及 Repository。
- 新增商品留言列表、发布和删除接口。
- 商品详情页增加“大家都在问”公开留言区域。
- 留言显示校园认证状态和卖家身份标识。
- 留言者可以删除自己的留言，商品卖家可以管理自己商品下的留言。
- 私密联系方式仍通过原有商品咨询功能沟通，公开留言与私聊业务分离。

### 4. 同款商品价格对照

- 商品详情页增加“查看同款价格对照”入口。
- 新增独立价格对照页 `price-compare.html`。
- 后端按照商品分类和标题相似度匹配同款、相似及同类商品。
- 展示参考样本数、最低挂牌价、平均挂牌价和最高挂牌价。
- 展示当前商品与同类均价的差异比例。
- 明确标注数据为 StudentBay 校内挂牌价，不将挂牌价描述为真实成交价。
- 增加机械键盘同款演示样本，方便课程演示价格对照功能。

### 5. 页面和交互优化

- 补充地址卡片、订单进度、底部服务弹层、留言列表和价格柱状对照样式。
- 桌面端和移动端均增加响应式布局。
- 保持 StudentBay 校园绿色主题和统一组件风格。

### 6. 评论发布故障修复

- 定位并修复异步提交结束后继续读取失效事件对象的问题。
- 提交前保存表单引用，留言成功后正确清空输入框并重新加载留言列表。
- 修复页面显示 `Cannot read properties of null (reading 'reset')` 但留言无法正常刷新的现象。

### 7. 二手单件库存购物车

- 按二手交易场景固定每种商品数量为 1，不提供数量加减。
- 增加全选、取消全选、批量删除和失效商品提示。
- 增加移入收藏、同款比价和分享商品链接功能。
- 同时结算 3 件及以上商品时，自动发放一张满 50 元减 5 元的平台专属券，有效期 30 天。

### 8. 任务中心与金币体系

- 导航栏新增独立任务中心和金币余额入口。
- 将任务分为“今日任务”和“长期成长任务”，并提高实际完成难度。
- 今日必做任务包括校园签到、当天加入 3 件商品、发布 2 条公开留言和发送 3 条商品咨询。
- 今日可选任务为发布 1 件校园闲置；成长任务包括累计下单 3 笔、完成交易 3 笔和发布 5 件商品。
- 每日任务根据当天数据库记录统计进度，领取记录按日期隔离，零点自动更新。
- 新增每日 3 次“掷骰子校园寻宝”，用户沿 20 格校园棋盘前进。
- 棋盘包含金币格、神秘格、校园漫步格和任务大奖格；任务大奖格要求完成全部今日必做任务。
- 骰子位置、每日次数与当日游戏收益持久化保存，刷新页面不会重置机会。
- 建立用户金币钱包、任务领取记录和金币流水数据表。
- 结算页支持金币抵扣，兑换比例为 10 金币抵 1 元，每单最多抵扣应付金额的 20%。
- 订单明细记录金币使用数量和抵扣金额，支付成功页展示多件购买奖励。

## 新增或调整的主要接口

| 方法 | 接口 | 功能 |
|---|---|---|
| `PUT` | `/api/account/addresses/{id}` | 修改收货地址 |
| `DELETE` | `/api/account/addresses/{id}` | 删除收货地址 |
| `GET` | `/api/products/{id}/comments` | 获取商品公开留言 |
| `POST` | `/api/products/{id}/comments` | 发布公开留言 |
| `DELETE` | `/api/products/{id}/comments/{commentId}` | 删除公开留言 |
| `GET` | `/api/products/{id}/comparisons` | 获取同款及相似商品价格数据 |
| `GET` | `/api/rewards/summary` | 获取金币余额、任务和金币流水 |
| `POST` | `/api/rewards/tasks/{code}/claim` | 领取已完成任务的金币 |
| `POST` | `/api/rewards/game/play` | 进行每日骰子寻宝 |
