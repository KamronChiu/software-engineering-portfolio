## 今日目标

完成 StudentBay 项目的基础工程搭建和交易核心业务闭环，平台的搭建，使商品能够从浏览、购买、支付进入卖家履约和买家收货阶段，同时为组员后续开发商品、用户及后台模块提供可联调的项目结构。

## 今日完成内容

### 1. Spring Boot 与数据库环境

- 使用 Java 17 和 Maven 创建 Spring Boot 项目。
- 接入 Spring Web MVC、Spring Data JPA、Validation 和 MySQL Connector/J。
- 创建 MySQL 数据库 `studentbay`。
- 使用环境变量配置数据库账号和密码，避免在仓库中提交本地密码。
- 配置 Hibernate 自动更新数据表结构。
- 解决未配置 DataSource 导致的 Spring Boot 启动失败问题。
- 验证 Tomcat、HikariCP、Hibernate 和 MySQL 能够正常启动并建立连接。

### 2. Git 与团队分支协作

- 将本地 IDEA 项目关联到 Gitee 仓库。
- 从远程 `develop` 分支创建个人开发分支 `user1`。
- 完成 `user1` 分支提交和推送。
- 明确个人分支开发、合并最新 `develop`、Pull Request 回到 `develop` 的协作流程。
- 配置 `.gitignore`，排除 IDEA 配置、构建目录和本地敏感配置。

### 3. 用户与登录态基础

- 建立用户、角色、账号状态和校园认证数据模型。
- 使用 Session 保存当前登录用户，替代前端固定用户编号。
- 增加普通用户和管理员角色校验。
- 提供登录、获取当前用户和退出登录接口。
- 初始化买家、卖家和管理员演示账号。

### 4. 商品浏览与发布联调功能

- 实现商品发布、商品列表、关键词搜索和分类筛选。
- 支持商品成色筛选与价格排序。
- 实现商品详情、商品状态、浏览次数和卖家信息展示。
- 发布商品时支持在地图上点击选择交易位置。
- 商品详情支持显示交易地点。
- 修复演示商品卖家归属错误导致买家看到卖家操作的问题。

### 5. 地图性能优化

- 将商品详情地图改为按需加载，默认只展示地点信息卡片。
- 用户点击“查看小地图”后才加载地图。
- 限制地图展示范围和高度。
- 禁用详情地图的滚轮缩放、拖动、双击缩放和键盘操作。
- 避免用户滚动到地图区域时页面被地图捕获，改善卡顿问题。

### 6. 购物车与确认订单

- 实现商品加入购物车、删除购物车商品和购物车数量提醒。
- 支持选择一件或多件商品进入结算。
- 在商品详情增加“立即购买”，可直接进入确认订单页面。
- 将购物车、确认订单、支付和支付结果拆分为独立页面。
- 确认订单时支持选择快递配送或校内自提。
- 支持新增和选择收货地址。
- 支持选择优惠券并计算优惠金额。
- 支持选择微信支付、支付宝或校园卡等支付方式。

### 7. 订单与支付流程

- 建立 `orders` 和 `order_item` 数据模型。
- 生成平台订单编号并保存商品快照和金额信息。
- 实现待付款、已付款、已预约取件、已发货、已完成和已取消等订单状态。
- 实现独立支付页面和支付成功页面。
- 买家可以查看自己购买的订单并确认收货。
- 卖家可以查看自己卖出的订单并处理履约。
- 校内自提订单使用独立的当面交付流程，不要求预约快递。

### 8. 卖家预约快递与物流轨迹

- 卖家可为已付款的快递订单选择快递公司和上门取件时间。
- 预约成功后自动分配快递员、隐私联系电话和六位取件码。
- 新增独立物流详情页面。
- 物流页面展示预计取件时间、预计送达时间、配送地址和运单号。
- 卖家可在快递员揽收后填写运单号并确认发货。
- 建立物流轨迹数据表和物流状态：

```text
BOOKED
→ PICKED_UP
→ IN_TRANSIT
→ AT_DESTINATION
→ OUT_FOR_DELIVERY
→ DELIVERED
```

- 支持预约成功、快递员取件、运输途中、到达配送站、正在派送和确认签收等物流事件。
- 买卖双方均可从订单页面进入物流详情。
- 取件码仅向卖家展示，买家端进行隐私保护。

### 9. 商品咨询、收藏与举报

- 按商品维度创建咨询会话。
- 区分“我咨询的商品”和“别人咨询我的商品”。
- 支持发送消息、读取消息和未读消息数量提醒。
- 支持商品收藏和收藏列表。
- 支持提交商品举报。

### 10. 管理后台联调功能

- 实现用户列表和账号启用、停用操作。
- 实现商品列表和商品上下架操作。
- 实现举报审核、驳回及违规商品下架。
- 实现地图缩放配置。

### 11. 页面与交互优化

- 校园绿色主题、校园建筑元素、卡片和响应式布局。
- 解决项目启动后访问根路径出现 Whitelabel 404 页面的问题。

## 遇到的问题与解决方案

| 问题 | 解决方案 |
|---|---|
| Spring Boot 无法配置 DataSource | 创建 MySQL 数据库并配置 URL、用户名、密码和驱动 |
| 项目启动成功但根路径返回 404 | 新增平台首页和页面导航 |
| 页面使用固定买家编号 | 改为 Session 当前用户机制 |
| 商品详情显示“继续发布”而不是购买 | 修复演示商品卖家归属，并增加“立即购买”入口 |
| 滚动到地图后页面卡顿 | 地图延迟加载、缩小范围并关闭滚轮和拖动交互 |
| 预约快递后缺少业务反馈 | 新增快递员信息、取件码和物流轨迹页面 |
| 本地分支与远程仓库未关联 | 配置 Gitee `origin` 并建立个人跟踪分支 |
