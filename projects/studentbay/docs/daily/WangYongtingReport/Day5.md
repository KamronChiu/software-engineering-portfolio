## 今日目标

在 Day 3 个人中心与 Day 4 注册、评价体系的基础上，把"个人主页"升级为完整的"我的空间"：以三个面板集中呈现我发布的宝贝、我收到的评价与我最近的重要动态，并把账号设置页重构为可扩展的设置中心（个人信息、级联地址 + 地图定位、修改密码、主题设置四个面板）。同时修复主页商品图片全部无法加载的问题，保证线上展示稳定可用。

## 今日完成内容

### 1. 我的空间页面（my-space.html）

- 新增"我的空间"页面，从个人主页头像处进入，采用与任务中心一致的 hero 头部：左侧大尺寸圆形头像，右侧展示空间标题、昵称、学校信息与身份徽章（学生认证、管理员等）。
- 页面主体为三个可切换面板：宝贝 / 评价 / 动态。
- 宝贝面板：以商品卡片网格展示我发布的全部宝贝，无论是否卖出都留档；卡片带状态角标（在售 / 已预订 / 已下架等），已卖出的商品卡片整体置灰，一眼看出哪些宝贝已经成交。
- 评价面板：双子标签切换"买家评价我"与"卖家评价我"，顶部汇总展示收到的评价总数与平均星级，下方按时间倒序展示每条评价（评价人头像、昵称、星级与文字）。
- 动态面板：以时间轴形式展示我的近期动态——上架新宝贝、宝贝被买走等重要时刻，每条动态带类型图标、商品标题与发生时间。

### 2. 用户动态记录体系

- 新增动态实体 `UserActivity` 与类型枚举 `ActivityType`（发布宝贝 / 宝贝被买走等），新增 `UserActivityRepository` 支持按用户倒序查询动态。
- 商品发布成功时自动为用户记录"上架了新宝贝"动态；买家支付成功时自动为卖家记录"宝贝被买走"动态，与订单支付流程（含幂等键路径）衔接，避免重复记录。
- 新增 `GET /api/account/activities` 接口返回当前用户动态列表（类型、关联商品、标题、时间）。
- 演示数据初始化器为存量演示商品自动补种历史动态，让老账号打开动态面板即有内容可看。

### 3. 设置中心重构（settings.html）

- 账号设置页重构为"菜单 + 面板"结构的设置中心：首页为入口菜单（个人信息 / 地址管理 / 修改密码 / 主题设置），点击进入对应子面板，面板内可返回设置首页。
- 个人信息面板：在 Day 3 基础上强化头像交互——选择新头像后先本地预览、点"保存修改"才真正生效，支持 jpg / png / webp / gif（最大 5MB）。
- 地址管理面板：收货地址支持国家 / 省份 / 城市 / 区县 / 街道园区五级级联选择 + 楼栋门牌等具体位置填写；填写后点击"定位到已选地址"地图自动跳转，再点击地图上的具体位置可微调标记；每条地址可设为默认地址。
- 修改密码面板：输入原密码通过校验后设置新密码（至少 6 位），并提供确认密码输入。
- 主题设置面板：显示模式支持"跟随系统 / 浅色 / 深色"三种，并提供主题色（按钮、导航高亮、选中框、链接）与导航栏颜色的自定义色板选择。

### 4. 主题系统

- 页面根节点以 `data-theme` 标记当前主题，全套深浅色组件样式按主题变量覆盖，新增页面与既有页面统一跟随。
- 主题设置与主题色选择即时生效并持久化，刷新后保持用户选择。

### 5. 收货地址坐标化

- `DeliveryAddress` 实体增加经纬度字段，地址保存时记录地图标记位置。
- 级联地址、地图定位选点与坐标自愈配合，保证下单、面交协商等场景拿到的地址既可读又可定位。

### 6. 商品图片加载问题修复

- 定位主页商品图全部加载失败的三层根因并逐一修复：
  - 接口层：修复编译参数缺失导致的接口 500（商品列表无法返回），以携带参数名信息的全量方式重新编译并重启验证；
  - 图片层：将原先不可达的外链演示图替换为本地图片资源，数据库商品图片地址统一更新为 `/uploads/demo-*.jpg`，走本站上传目录访问；
  - 兜底层：修复图片加载失败时的备用图（data URI）因引号编码问题导致 `onerror` 失效的缺陷，图片异常时能正确降级显示。

### 7. 我的空间视觉收尾

- 我的空间 hero 向任务中心 `reward-hero` 视觉靠拢：白色标题文字、暖黄 eyebrow 与徽章、头像描边与投影统一，面板标题沿用任务中心 section-title 的排版层级。
- 页面在浅色 / 深色主题下均保持正确的文字对比度与状态色彩。

## 新增或调整的主要接口

| 方法 | 接口 | 功能 |
|---|---|---|
| `GET` | `/api/account/activities` | 当前用户的动态时间轴（倒序） |
| `PUT` | `/api/account/password` | 校验原密码后修改登录密码 |
| `PUT` | `/api/account/addresses/{id}` 等 | 收货地址增删改（含经纬度、默认地址）与地图定位数据 |
| `GET` | `/uploads/**` | 本地化商品图片静态访问 |

## 数据模型调整

新增数据表：

```text
user_activities
```

`delivery_addresses` 表新增字段：

```text
latitude
longitude
```

项目使用 `spring.jpa.hibernate.ddl-auto=update`，启动后自动建表与补字段，不要求清空现有业务数据。

## Day 5 总结

Day 5 把个人主页升级成了真正意义上的"我的空间"：宝贝、评价与动态三块信息在同一个页面里形成了用户维度的完整画像——发布的宝贝带状态留档，收到的评价带星级汇总，上架与成交的时刻沉淀为时间轴。动态记录体系在发布与支付两个关键节点自动埋点，配合演示数据的补种让功能开箱可见。设置中心从单一表单扩展为菜单式面板结构，级联地址与地图定位让收货信息从"文字描述"升级为"可定位坐标"，修改密码与主题自定义补齐了账号安全与个性化体验。最后修复的商品图片加载问题涉及编译、资源与前端兜底三层，排查过程也验证了本地化图片与 `/uploads/**` 基础设施的可用性，为后续迭代提供了稳定基础。
