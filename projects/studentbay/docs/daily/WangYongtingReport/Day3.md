## 今日目标

在 Day 2 已完成的商品浏览、购物车与订单基础之上，补齐用户侧的"个人中心"体验：让用户登录后有一个统一入口查看自己的收藏、咨询、购物车与订单，能够维护头像、昵称、认证邮箱和学校等个人资料，并为头像等图片文件建立可访问的上传目录基础设施。

## 今日完成内容

### 1. 个人主页聚合页（profile.html）

- 新增个人中心页面，顶部展示当前用户资料卡（头像、昵称、邮箱、学校等由接口实时填充）。
- 中部提供"我的服务"九宫格入口：我的收藏、商品咨询、购物车、我的订单、我买入的、我卖出的、发布闲置、任务中心，管理员账号额外显示管理后台入口。
- 收藏、购物车、咨询等入口带未读/数量角标（收藏与购物车角标、金币余额胶囊），数据在页面初始化时统一加载。
- 页面底部提供退出登录按钮，与导航栏登录状态联动。
- 导航栏与 `bought.html` 等既有页面增加跳转个人主页的入口。

### 2. 账号设置页（settings.html）

- 新增账号设置页面，支持更换头像：选择本地图片（jpg / png / webp / gif，不超过 5MB）后直接上传，页面即时预览新头像。
- 支持编辑用户名称、认证邮箱与学校，提交后保存。
- 认证邮箱修改后给出"下次登录请使用新邮箱"的明确提示。
- 资料卡、导航栏头像等全局组件同步展示更新后的头像与昵称。

### 3. 我买入的页面（bought.html）

- 新增"我买入的"列表页，展示当前用户已拍下的商品，支持从个人中心直达。

### 4. 后端个人资料接口与头像上传

- `PUT /api/account/profile`：更新昵称、邮箱与学校；邮箱统一转小写并做唯一性检查，与其他账号冲突时返回 409。
- `POST /api/account/avatar`：接收头像文件，校验类型与大小后落盘到 `uploads` 目录，并把访问地址写回用户头像字段。
- 新增 `WebConfig`：将 `/uploads/**` 请求映射到本地 `./uploads` 目录，使上传的图片可通过静态路径直接访问。
- `AppUser` 增加 `avatar_url` 字段，供个人资料卡、导航栏、消息与评价等场景统一展示头像。
- 全局异常处理器补充文件上传相关的异常兜底（文件过大、空文件等返回友好提示）。

### 5. 配置修复

- 将数据库账号从写死的配置文件改为环境变量注入（`DB_USERNAME` / `DB_PASSWORD`），避免敏感信息入库，也方便不同环境切换。
- 清理配置文件中重复/失效的上传配置项，上传目录统一收敛到 `WebConfig` 的 `/uploads/**` 映射管理。

## 新增或调整的主要接口

| 方法 | 接口 | 功能 |
|---|---|---|
| `PUT` | `/api/account/profile` | 更新昵称、认证邮箱与学校，校验邮箱唯一 |
| `POST` | `/api/account/avatar` | 上传头像文件并返回新头像地址 |
| `GET` | `/api/account/bought` | 当前用户买入的商品列表 |
| `GET` | `/uploads/**` | 访问本地上传目录中的图片文件 |

## 数据模型调整

`users` 表新增字段：

```text
avatar_url
```

项目使用 `spring.jpa.hibernate.ddl-auto=update`，启动后自动为已有用户表补充字段，不要求清空现有业务数据。

Day 3 完成了个人中心从"入口"到"内容"的闭环：个人主页聚合了收藏、咨询、购物车、订单、买卖与任务等全部高频入口，设置页承担了头像、昵称、邮箱与学校的资料维护，我买入的页面补齐了买家视角的订单留档。同时建立了 `/uploads/**` 图片访问基础设施与用户头像字段，为后续聊天头像、评价头像、我的空间等场景提供了统一的图片承载能力。
