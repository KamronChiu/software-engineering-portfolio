# StudentBay 业务结构

## 交易边界

- 商品为校园二手单品，同一商品进入结算后状态变为 `RESERVED`。
- 购物车可以同时选择多件商品；结算时按商品生成独立订单，便于不同卖家分别履约。
- 优惠券只应用到首个满足门槛的商品订单。
- 快递配送按订单收取配送费；校内自提不收配送费。

## 订单状态

```text
PENDING_PAYMENT → PAID → COURIER_BOOKED → SHIPPED → COMPLETED
```

- 买家：提交订单、付款、确认收货。
- 卖家：预约快递、填写运单、确认发货。
- 订单所属用户之外无法查看或改变订单。

## 物流状态

```text
BOOKED → PICKED_UP → IN_TRANSIT → AT_DESTINATION → OUT_FOR_DELIVERY → DELIVERED
```

- 预约成功后生成快递员、隐私号码、预计取件时间与六位取件码。
- 确认发货后记录揽收、运输、到站、派送与签收轨迹。
- 买卖双方均可查看物流，只有卖家可以在预约取件后填写运单并确认发货。

## 消息边界

- 会话由 `商品 + 买家 + 卖家` 唯一确定。
- 买家列表展示“我咨询的商品”，卖家列表展示“别人咨询我的商品”。
- 打开会话后，将对方发送且未读的消息标记为已读。

## 地图配置

公共地图中心点、缩放级别、瓦片地址和版权标注保存在 `app_config` 表，可由管理员调整。发布页保存商品位置经纬度，详情页只展示该商品的交易位置。
